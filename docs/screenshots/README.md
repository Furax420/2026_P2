# Captures d'écran à ajouter

Enregistrer quatre captures PNG dans ce dossier, sans inclure les barres du navigateur :

- `dashboard-desktop.png` — route `/`, viewport 1440 × 900 px ;
- `dashboard-mobile.png` — route `/`, viewport 390 × 844 px ;
- `country-detail-desktop.png` — route `/country/1`, viewport 1440 × 900 px ;
- `country-detail-mobile.png` — route `/country/1`, viewport 390 × 844 px.

Utiliser une capture de page entière avec le viewport indiqué. Avant chaque capture, attendre la fin de l'écran « Chargement... ». Sur mobile, conserver le classement replié afin de montrer la mise en page initiale de la page détail.
